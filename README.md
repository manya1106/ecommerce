# Development Workspace

A collection of web development projects showcasing various technologies and frameworks.

## Projects Overview

### 1. **ShopHub - AI E-commerce Store** (`ai_ecommerce/`)
A fully functional e-commerce website built with vanilla HTML, CSS, and JavaScript.

**Features:**
- Responsive product catalog with search and filtering
- Shopping cart functionality
- Product sorting (price, popularity)
- Hero section and featured products
- Navigation with cart counter

**Tech Stack:** HTML5, CSS3, JavaScript (Vanilla)

**Files:**
- `index.html` - Main page structure
- `styles.css` - Styling and responsive design
- `script.js` - Shopping cart and product logic

---

### 2. **React App with Vite** (`myreactapp/`)
Modern React application using Vite for fast development and optimized builds.

**Features:**
- React 19 setup with Vite bundler
- ESLint configuration for code quality
- Hot module replacement for fast development
- Optimized production builds

**Tech Stack:** React 19, Vite, JavaScript (ES modules)

**Available Scripts:**
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build

---

### 3. **Simple Web Server** (`SimpleWebServer.java`)
A lightweight HTTP server implementation in Java.

**Features:**
- Listens on port 8080
- Multi-threaded client handling
- Basic HTTP request parsing
- Lightweight and educational implementation

**Tech Stack:** Java

**How to run:**
```bash
javac SimpleWebServer.java
java SimpleWebServer
```

### 5. **Todo Application** (`todo/`)
A full-stack todo application with Flask backend and frontend interface.

**Features:**
- REST API with Flask
- CORS support for cross-origin requests
- In-memory todo storage
- Create, read, update, and delete tasks
- Timestamp tracking

**Tech Stack:** Python (Flask, Flask-CORS), HTML, CSS, JavaScript

**Available Endpoints:**
- `GET /todos` - Retrieve all todos
- `POST /todos` - Create a new todo
- (Additional endpoints for update/delete operations)

**How to run:**
```bash
pip install flask flask-cors
python app.py
```

## Getting Started

### Prerequisites
- Node.js (for React app)
- Python 3.7+ (for Flask todo app)
- Java JDK (for SimpleWebServer)
- Web browser (for static HTML projects)

### Installation

**For React App:**
```bash
cd myreactapp
npm install
npm run dev
```

**For Todo Flask App:**
```bash
cd todo
pip install -r requirements.txt
python app.py
```

**For Static HTML Projects:**
Simply open the `index.html` file in a web browser or use the SimpleWebServer to serve them.
